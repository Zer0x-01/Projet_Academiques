Cookies et stockage local

Ce site utilise le stockage local du navigateur (localStorage) uniquement pour améliorer votre expérience utilisateur :

  • Mode éco-responsable : Sauvegarde de votre préférence de thème (mode clair ou mode sombre)

Important : Aucune donnée personnelle n'est collectée via ces mécanismes de stockage. Aucune information n'est transmise à des tiers ou à des serveurs externes.

Vous pouvez à tout moment supprimer ces données en :

  • Vidant le cache de votre navigateur
  • Utilisant le mode navigation privée
  • Désactivant le JavaScript (attention : cela affectera le fonctionnement du site)

Aucun cookie tiers n'est utilisé sur ce site (pas de Google Analytics, pas de publicité, pas de trackers).
